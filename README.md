# DeepSolo

**输入你已有的策略（哪怕亏钱），通过多智能体涌现进化，输出赚钱的可执行策略，过程全程可视化。**

DeepSolo 是一个开源的策略涌现引擎。它接收你的交易策略作为"基因种子"，通过心跳衍生和社区讨论双层进化机制，让策略自动繁殖、竞争、淘汰，涌现出比原始策略更优的可执行策略。

## 核心理念

```
你的策略（可能亏钱）
      │
      ▼
┌─────────────────────────────────────────┐
│         DeepSolo 策略涌现世界            │
│                                         │
│  基础 NPC（6个）永驻，每天更新回测数据    │
│                                         │
│  心跳衍生 ── 每6h 综合 NPC → 诞生新 NPC  │
│  讨论衍生 ── NPC 讨论 → 更优 → 诞生 NPC  │
│  末位淘汰 ── NPC > 1000 → 淘汰最弱者     │
│  天道巡逻 ── 违背可交易原则 → 自然灭亡    │
│                                         │
│  全程可视化：像素社区里的 NPC 自治世界    │
└─────────────────────────────────────────┘
      │
      ▼
涌现出更优的可执行策略
```

## 主流程

### 1. 世界初始化

用户导入 6 个基础策略（已有的既定策略），每个策略对应一个**基础 NPC**，拥有独立的人格、策略规则和回测数据。基础 NPC **永驻世界**，每天更新回测数据和收益率。

### 2. 心跳衍生（定时触发）

世界有一个**心跳机制**，每 6 小时触发一次：

```
心跳触发
  ├─ NPC 总数 ≤ 10：综合所有 NPC 的状态和表现 → 诞生 1 个衍生 NPC
  └─ NPC 总数 > 10：综合筛选优质 NPC → 诞生 1 个衍生 NPC
```

衍生 NPC 基于被选中 NPC 的策略特征综合生成，继承部分基因，也带有新的变异。

### 3. 讨论衍生（事件驱动）

世界中的 NPC 可以相互讨论回测：

```
NPC A 和 NPC B 讨论
  → LLM 基于两者策略碰撞出新想法
  → 内置回测引擎测试新想法
  → 回测结果 > 所有参与讨论者的结果 → 诞生新 NPC
  → 否则 → 不诞生，仅记录讨论
```

### 4. 末位淘汰（人口控制）

当世界中的 NPC 数量超过 1000 个时，触发末位淘汰机制：
- 不再新增 NPC，而是替换表现最差的 NPC
- 淘汰标准：回测收益率、策略稳定性、存活时间等综合评分最低者
- 保证世界的多样性和竞争力

### 5. 天道巡逻（合规净化）

后期引入**天道巡逻**机制：
- 定期检查所有 NPC 的策略
- 当策略违背可交易原则（如过度杠杆、违规操作、逻辑崩溃等）→ 该 NPC 自然灭亡
- 保证世界中策略的健康性

### 6. LLM 资源分配

```
普通衍生 NPC → 共享 LLM 实例（角色扮演、策略讨论）
优质 NPC（排行榜前列）→ 分配独立 LLM 实例（深度策略优化）
```

## 项目结构

```
deepsolo/
├── packages/
│   ├── core/              # 策略仓库 + 记忆系统
│   │   └── deepsolo/

│   │       ├── storage/   # SQLite 存储层
│   │       └── memory/    # 策略记忆系统
│   ├── evolution/         # 进化引擎
│   │   └── deepsolo_evolution/
│   │       ├── heartbeat/    # 心跳衍生
│   │       ├── discussion/   # 社区讨论
│   │       ├── elimination/  # 末位淘汰 + 天道巡逻
│   │       └── backtest/     # 内置回测引擎
│   ├── visual/            # 像素社区可视化（Phaser）
│   └── connector/         # 外部策略接入适配器
├── docs/                  # 文档
├── examples/              # 示例策略
├── tests/                 # 测试
└── .github/               # CI/CD & 模板
```

## 快速开始

> 项目正在开发中，敬请期待。

```bash
# 安装
pip install deepsolo

# 初始化策略仓库
deepsolo init

# 接入你的 6 个基础策略
deepsolo strategy add --name "momentum_alpha" --file strategy.json
deepsolo strategy add --name "mean_revert" --file strategy.json
# ... 共 6 个

# 启动涌现世界
deepsolo evolve

# 查看可视化（像素社区）
deepsolo visual
```

## 技术栈

- **语言**：Python 3.11+（后端）+ TypeScript（前端）
- **前端**：Phaser（像素社区可视化）
- **存储**：SQLite（初期）→ 图数据库（后期可选）
- **通信**：前后端文件中转（JSON）
- **LLM**：OpenAI 兼容接口（支持任意模型）
- **回测**：内置回测引擎
