# 内嵌家具遮挡编辑器 MVP

目标：在游戏内直接标注家具的位置、碰撞框和遮挡点，并且立即看到玩家碰撞/遮挡效果。编辑器优先追求所见即所得，不要求先导出再验证。

## MVP 范围

第一版只处理观察者小屋已有家具，不做独立产品、不做文件写入。遮挡 mask 会在运行时即时生成一层前景裁剪贴图，编辑时直接看到真实遮挡效果。

支持：

- `F2`：开启/关闭编辑模式。
- 鼠标拖动黄色圆环锚点：修改 `localX/localY`。
- 鼠标拖动紫色实心遮挡点：修改 `depthLocalX/depthLocalY`。
- 黄色和紫色重合时，普通拖动优先移动锚点，按住 `Shift` 拖动优先移动遮挡点。
- 鼠标拖动红色碰撞框四角：修改 `collider`。
- `M`：开启/关闭当前选中家具的多边形遮挡 mask 编辑。
- mask 模式下点击家具图片：新增橙色 mask 点。
- mask 模式下拖动橙色点：修改 mask 点。
- `Alt` + 点击橙色点，或右键橙色点：删除指定 mask 点。
- `Backspace` / `Delete`：删除当前选中的 mask 点；没有选中点时删除最后一个点。
- `C`：清空当前选中家具的 mask。
- 编辑结果会自动保存到浏览器 `localStorage`，刷新页面后自动恢复。
- `R`：清空当前房间本地保存，并恢复代码里的默认参数。

## 设计原则

家具配置仍然以 `IndoorFurnitureLayout.ts` 为唯一数据源。编辑器运行时直接修改这些对象，因此：

- 渲染位置立即更新。
- 碰撞检测立即使用新框。
- 遮挡排序立即使用新点。
- mask 多边形会立即裁出一层前景贴图，显示在玩家上方。
- 每次拖拽结束或增删 mask 点后，会把当前房间布局写入 `localStorage`。

当前保存 key：

```text
deepsolo_furniture_editor_layouts:birth_house
```

这份保存只存在当前浏览器里，不会自动改 `IndoorFurnitureLayout.ts`。因此它适合作为快速调参和验收层；确认一组参数稳定后，再考虑迁移为 JSON 文件或后端保存。

## 坐标说明

编辑器操作的是房间内侧坐标，也就是 `localX/localY`。观察者小屋当前真实地图坐标 = local 坐标 + `(3, 3)`。

调试叠层含义：

- 蓝色网格：真实地图格。
- 红色框：碰撞框。
- 黄色圆环：家具锚点。
- 紫色实心点：遮挡排序点。若与黄色圆环重合，会显示在圆环内部。
- 橙色点/面：当前家具的多边形遮挡 mask，点坐标存储在家具原图像素空间。
- 绿色点：玩家脚点。

编辑模式左下角会显示一块中文操作说明面板，包含选择家具、调整碰撞、调整遮挡、编辑 mask、自动保存和重置的快捷键说明。点击面板标题或按 `H` 可以收起/展开。左上角面板只显示当前选中家具的实时参数，避免操作说明和参数混在一起。

## 多边形遮挡 mask

`occluderMask` 是一组图片像素坐标：

```ts
occluderMask: [
  { px: 20, py: 190 },
  { px: 330, py: 190 },
  { px: 330, py: 300 },
  { px: 20, py: 300 },
]
```

它描述“这张家具图里哪一块作为前景遮挡层”。坐标不是地图坐标，也不是房间 local 坐标，而是原 PNG 左上角为 `(0, 0)` 的像素坐标。这样即使家具在游戏里改变 `scale`，mask 仍然能跟着图片正确缩放。

当前 MVP 会把同一家具渲染两遍：底层整图正常参与 depth，前景层只显示 `occluderMask` 区域并盖在玩家上方。拖动橙色点时，前景层会即时重建，所以可以直接用玩家走动验证遮挡是否自然。

## 后续演进

后续可以把 `IndoorFurnitureLayout.ts` 迁移成 JSON：

- `asset_meta.json`：每种家具的默认锚点、默认碰撞、默认遮挡点。
- `scene_layout.json`：某个场景里放了哪些家具实例。

再进一步可以加多边形碰撞、文件级保存和独立编辑器。
