# 内嵌家具遮挡编辑器 MVP

目标：在游戏内直接标注家具的位置、碰撞框和遮挡点，立即看到玩家碰撞/遮挡效果，并导出一份可回写到 `IndoorFurnitureLayout.ts` 或后续 JSON 配置的布局数据。

## MVP 范围

第一版只处理观察者小屋已有家具，不做独立产品、不做文件写入、不做复杂遮挡 mask。

支持：

- `F2`：开启/关闭编辑模式。
- 鼠标拖动黄色锚点：修改 `localX/localY`。
- 鼠标拖动紫色遮挡点：修改 `depthLocalX/depthLocalY`。
- 鼠标拖动红色碰撞框四角：修改 `collider`。
- `F4`：导出当前家具配置 JSON 到剪贴板，并输出到 console。

## 设计原则

家具配置仍然以 `IndoorFurnitureLayout.ts` 为唯一数据源。编辑器运行时直接修改这些对象，因此：

- 渲染位置立即更新。
- 碰撞检测立即使用新框。
- 遮挡排序立即使用新点。
- 导出的 JSON 可以作为后续持久化文件格式的基础。

## 坐标说明

编辑器操作的是房间内侧坐标，也就是 `localX/localY`。观察者小屋当前真实地图坐标 = local 坐标 + `(3, 3)`。

调试叠层含义：

- 蓝色网格：真实地图格。
- 红色框：碰撞框。
- 黄色点：家具锚点。
- 紫色点：遮挡排序点。
- 绿色点：玩家脚点。

## 后续演进

后续可以把 `IndoorFurnitureLayout.ts` 迁移成 JSON：

- `asset_meta.json`：每种家具的默认锚点、默认碰撞、默认遮挡点。
- `scene_layout.json`：某个场景里放了哪些家具实例。

再进一步可以加遮挡 mask，多边形碰撞、自动保存和独立编辑器。
