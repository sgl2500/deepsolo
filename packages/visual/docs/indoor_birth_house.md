# 观察者小屋 (birth_house) 装修文档

## 基本信息

| 属性 | 值 |
|------|------|
| 地图尺寸 | 20 × 20 |
| 房间中心 | (10, 10) |
| 玩家出生 | (10, 10) |
| 出口位置 | (10, 19) → 世界地图 (50, 58) |
| 引路人NPC | (10, 16) |
| 等距瓦片 | 36×18 px (half: 18×9) |
| 画面 | 1280×720 |

## 坐标系说明

```
等距视图方向:
        上 (远离屏幕)
       ↗
  左 ←   → 右
       ↘
        下 (靠近屏幕)

row 增大 → 屏幕右下
col 增大 → 屏幕左下
depth = col + row  (值越大越靠前/越靠近观察者)

玩家出生 (col=10, row=10) → depth=20
走到门口 (col=10, row=19) → depth=29
```

## 图层说明

| 图层 | JSON字段 | 渲染方式 | depth | 用途 |
|------|----------|----------|-------|------|
| Layer 0 | `earth` | Canvas 画布 (静态) | N/A | 地板砖 |
| Layer 1 | `surface` | Phaser 精灵 | col+row | 墙壁、家具、门框 |
| Layer 2 | `building` | Phaser 精灵 | col+row+0.5 | **遮挡装饰** — 会覆盖在前方玩家上面 |
| 高度 | `surfaceHeight` | Y轴偏移 | N/A | 垂直提升 (当前全为4) |

## 装修规划

> 在下方指定贴图修改，格式：
> `操作: 层(col, row) → 贴图ID`
> 例如: `添加: surface(5, 2) → 836`
> 例如: `移除: building(7, 11)`

### 第一轮修改

1. `修改: earth(全房间) → 6` — 地板从 1138(石砖) 改为 6(草地) ✓
2. `重构: surface(四周墙壁)` — 从旧墙贴图(1746/2142系列)换为新墙贴图(810/817/837/839系列) ✓
3. `扩大: 地图 20×16 → 20×20` — 中心 (10,8)→(10,10)，出口 (8,15)→(10,19) ✓
4. `清理: building层` — 移除旧调试布局 ✓

### 第二轮修改 — 墙壁/地板对齐

5. `修复: 墙壁与地板间的缝隙` — 在 earth 层为墙壁下方铺草，利用 Canvas 渲染时墙壁覆盖草地的特性填满 4px 间隙 ✓
   - row 0 cols 0-18: 铺草（填满顶部墙壁下方）
   - col 0 rows 1-17: 铺草（填满左侧墙壁下方）
   - row 18 col 0: 保持 0（避免窄角墙 846 处草地溢出）
   - row 19: 全部保持 0（底部墙壁前草地会溢出）
   - col 19: 保持 0（右侧墙壁窄，草地易溢出）
