## 添加一个新室内场景的完整步骤

以「新闻中心」为例，从零到可进入。

### Step 1: 准备室内地图 JSON

**文件位置**: `public/assets/indoor_maps/indoor_{id}.json`

**室内地图结构**（参考 `indoor_teahouse.json`）:

```
40x40 网格
┌────────────────────────┐
│      (全0 空白区)       │
│  ┌──────────────────┐  │
│  │  墙 838...838  墙  │  │  ← row 1: 顶墙 (845=左上角, 847=右上角)
│  │  壁              壁  │  │  ← row 2~18: 侧墙 (837)
│  │  壁   地面 588   壁  │  │  ← earth 层用 588 填充房间区域
│  │  壁              壁  │  │
│  │  壁  307 307  壁  │  │  ← row 19: 底墙 (846=左下角, 869=右下角, 307=门)
│  └──────────────────┘  │
│      (全0 空白区)       │
└────────────────────────┘
```

**关键字段**:
- `cx`, `cy` — 房间视觉中心（通常 10, 10）
- `earth[row][col]` — 地面瓦片（0=空, 588=室内地板）
- `surface[row][col]` — 墙壁/物体（0=可通过, 307=门口可通过, 其他=阻挡）
- `smapTileIds` — 用到的所有瓦片 ID 列表

**可用瓦片 ID**（已在 BootScene 中预加载）:
| ID | 用途 |
|---|---|
| 588 | 室内地板 |
| 307 | 门口（可通行） |
| 837 | 侧墙 |
| 838 | 横墙 |
| 845 | 左上角墙 |
| 846 | 左下角墙 |
| 847 | 右上角墙 |
| 869 | 右下角墙 |

**生成脚本**（Node.js，在 `packages/visual/` 目录下运行）:

```bash
node -e "
const w = 40, h = 40, cx = 10, cy = 10;
const earth = Array.from({length: h}, (_, r) =>
  Array.from({length: w}, (_, c) =>
    (r >= 1 && r <= 20 && c >= 1 && c <= 19) ? 588 : 0
  )
);
const surface = Array.from({length: h}, () => Array(w).fill(0));
surface[1][1] = 845;
for (let c = 2; c <= 18; c++) surface[1][c] = 838;
surface[1][19] = 847;
for (let r = 2; r <= 18; r++) { surface[r][1] = 837; surface[r][19] = 837; }
surface[19][1] = 846;
for (let c = 2; c <= 9; c++) surface[19][c] = 838;
surface[19][10] = 307; surface[19][11] = 307;
for (let c = 12; c <= 18; c++) surface[19][c] = 838;
surface[19][19] = 869;
const map = { width: w, height: h, cx, cy, earth, surface, smapTileIds: [307, 588, 837, 838, 845, 846, 847, 869] };
console.log(JSON.stringify(map));
" > public/assets/indoor_maps/indoor_{id}.json
```

将 `{id}` 替换为建筑 ID（如 `datacenter`）。

### Step 2: 建筑定义（BuildingData.ts）

在 `src/data/BuildingData.ts` 的 `BUILDINGS` 数组中添加：

```typescript
makeSimpleIndoor('{id}', entryX, entryY),
```

`makeSimpleIndoor` 会自动生成标准参数：
- `indoorMapKey: 'indoor_{id}'` → 对应 `public/assets/indoor_maps/indoor_{id}.json`
- `spawnX: 9, spawnY: 9` — 玩家在室内的出生点
- `exitX: 10, exitY: 17` — 室内出口位置（底墙门口附近）

**必须确认**: `spawnX/spawnY` 和 `exitX/exitY` 在室内地图的**可通行区域**内（earth > 0 且 surface == 0 或 307）。

验证方法：
```bash
node -e "
const m = require('./public/assets/indoor_maps/indoor_{id}.json');
console.log('spawn(9,9):', m.earth[9][9] > 0 && (m.surface[9][9] === 0 || m.surface[9][9] === 307));
console.log('exit(10,17):', m.earth[17][10] > 0 && (m.surface[17][10] === 0 || m.surface[17][10] === 307));
"
```

### Step 3: BootScene 加载（自动，无需改动）

BootScene 已有循环加载所有 `BUILDINGS` 的室内地图：
```typescript
BUILDINGS.forEach(b => {
  this.load.json(b.indoorMapKey, `assets/indoor_maps/${b.indoorMapKey}.json`);
});
```

只要 JSON 文件在正确路径，**BootScene 无需修改**。

如果新地图使用了未预加载的 smap 瓦片 ID，需在 `collectSmapTileIds()` 中添加。

## 进入/退出流程（已有代码，无需改动）

```
玩家走向建筑入口 (entryX, entryY)
    → 距离 < entryRadius
    → SceneManager.checkBuildingEntry()
    → SceneManager.enterBuilding()
        → 状态 → TransitionOut（黑屏淡入 400ms）
        → 过渡中点：
            1. 从 Phaser cache 读取 indoorMapKey 对应的 JSON
            2. 玩家位置设为 spawnX, spawnY
            3. 玩家切换为室内地图数据 + 室内定位模式
            4. MapRenderer.switchToIndoor() 渲染室内地图
            5. 隐藏世界 Agent，创建室内 NPC
            6. 隐藏小地图、建筑标记
        → 状态 → TransitionIn（黑屏淡出）
        → 状态 → Indoor

玩家走向室内出口 (exitX, exitY)
    → 距离 < 2.0
    → SceneManager.checkExit()
    → SceneManager.exitBuilding()
        → 反向恢复世界地图状态
```

## 已知问题及处理

### 1. 玩家出生在建筑入口上会自动进入

玩家出生在 (50,50)，证券交易所也在 (50,50)，刷新后会立刻进入交易所。

**解决方案**: SceneManager 有 `startupBlocked` 启动保护，前 2 秒不检测建筑入口。

### 2. 世界地图有隐形墙

世界地图 surface 层有约 5% 的阻挡格（树、石头等），视觉上不明显。

**解决方案**: Player.isBlocked 在世界地图（`indoorMode === false`）时直接返回 false，仅室内保留碰撞检测。
