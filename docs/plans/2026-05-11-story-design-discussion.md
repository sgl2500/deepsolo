> 状态：讨论稿

## 1. 文档原则

本文件不是 AI 自由创作剧情的地方，而是剧情共创与确认记录。

规则：

- 只记录用户明确确认的剧情内容。
- 不自动新增主角背景、世界观、门派、NPC、反派、主线结局。
- 不把 AI 的建议写成既定事实。
- 如果需要提出方案，必须放在“待讨论选项”里，不能进入正式设定。
- 用户确认后，内容才能移入“已确认设定”。
- 后续剧情系统、任务系统、对话系统、事件系统，都以本文档的“已确认设定”为准。

#### 2.7.2 第一剧情点：数字门派掌门试炼

已确认：

- 触发地点：数字门派。
- 触发对象：数字掌门。
- 触发方式：进入数字掌门附近一定距离后，如果该剧情没触发过，则自动触发；靠近数字掌门按空格也走同一剧情入口。
- 剧情性质：触发战斗剧情。
- 剧情定位：出大地图进入自由探索后的第一个剧情点。

用户原始剧情意图：

```text
你对交易之道的领悟过于浅显，现在离我差距太远。
我受股神之托，就是开局的你的引导人，领你进交易之门。
我带你领会交易之道至高武学。
第一招，寂灭本心，贪婪恐惧灭。
第二招，重塑信心，勤勉自信起。
第三招，大道归一，神人合一，收。
这三招你看明白了吗？
你领悟多少就看你自己了。
在策略世界里，你需要不断探索和进阶，提升自己，最终明悟自身，才能返回真实交易世界。
```

剧情功能：

- 让数字掌门承接股神引导。
- 告诉玩家当前理解还浅。
- 通过“三招”建立交易之道的高级目标。
- 告诉玩家后续需要在策略世界探索、进阶、提升自己。
- 抛出最终方向：明悟自身，返回真实交易世界。

三招名称与含义：

| 顺序 | 招式 | 关键词 |
| --- | --- | --- |
| 第一招 | 寂灭本心 | 贪婪、恐惧、灭 |
| 第二招 | 重塑信心 | 勤勉、自信、起 |
| 第三招 | 大道归一 | 神人合一、收 |

已确认实现规则：

- 这是一段剧情演示，不是玩家必须打赢的挑战。
- 演示形式使用战棋战斗方式。
- 玩家观看演示。
- “贪婪”和“恐惧”都是心魔。
- “贪婪”和“恐惧”在战棋演示中是两个战斗角色。
- 战斗胜负不影响剧情推进。
- 剧情结束后给玩家秘籍：《交易心法》。

#### 2.7.3 第二剧情点：策略茶馆寻路

已确认：

- 触发时机：主角从数字门派出来之后。
- 前置状态：主角已经领悟《交易心法》第一重。
- 主角状态：主角深刻知道了“大道是什么”，并踏上一条修行交易之路。
- 主角困境：一开始他很迷茫，不知道天大地大，应该去哪。
- 下一处地点：主角发现前方有一个策略茶馆。
- 主角判断：策略茶馆里应该能获取一些灵感。
- 茶馆剧情的主要作用是间接告诉主角：这个世界可以做什么。
- 当前世界主要已有两大门派成立：数字门派和 A 股门派。
- 当前两大门派分别由数字门派掌门和 A 股门派掌门占据。
- 未来世界中可以有更多门派出现。
- 门派相关玩法包括：挑战、拜师、学习等一系列事情。
- 世界中还有试炼山洞，击败 boss 后可以获得一些成熟的策略秘籍。
- 世界中还能学习买地、建造等事情。
- 经过策略茶馆之后，大地图会开放更多地方。
- 策略茶馆会逐步告诉主角：哪些地方可以探索，哪些地方可能有剧情。
- 茶馆本身有很多人在讨论。
- 每个可开放地点或玩法，对应茶馆里的一个讨论场景。
- 玩家点击某个讨论场景后，开启对应讨论。
- 对应讨论结束后，会引发大地图变化。
- 大地图变化后，需要给玩家提示，例如“大地图的某某地方开启了”。

剧情功能：

- 承接数字掌门剧情结束后的自由探索。
- 表现主角从“听见大道”进入“开始修行”的状态变化。
- 用迷茫感提示玩家：世界很大，主线不会直接把答案塞给玩家。
- 用策略茶馆作为下一步轻引导，让玩家自然进入策略世界的信息场。
- 通过茶馆传闻和讨论，把门派、试炼山洞、策略秘籍、买地建造等世界玩法介绍给玩家。
- 让玩家理解“大地图上开放的新地方”各自可以做什么。
- 让后续地图开放、探索目标、剧情地点不显得突然。
- 把“听见消息”和“地图开放”绑定起来，让玩家知道新地点为什么出现。
- 让茶馆成为可反复进入的信息枢纽，而不是一次性对话。

茶馆交互结构：

```text
玩家进入策略茶馆
  → 看到多个讨论场景
  → 点击某个讨论场景
  → 播放该讨论内容
  → 设置对应世界状态
  → 大地图开放对应地点或玩法
  → 弹出提示：大地图的某某地方开启了
```

讨论场景与地图变化示例：

| 茶馆讨论方向 | 讨论后触发的大地图变化 |
| --- | --- |
| 门派传闻 | 开放或提示相关门派地点 |
| 试炼山洞传闻 | 开放试炼山洞 |
| 策略秘籍传闻 | 提示试炼 boss 可掉落成熟策略秘籍 |
| 买地建造传闻 | 开放或提示买地建造相关入口 |

第一批开放：

- A 股门派线索。
- 试炼山洞。
- 买地建造入口。

待讨论选项：

- 茶馆是否只负责开放地图和玩法认知，暂不推动《交易心法》第二重。
- 每个讨论场景是否只能触发一次，还是可以反复听。

#### 2.7.4 主线进阶：交易心法第五重后前往 A 股门派

已确认：

- 触发条件：玩家领悟《交易心法》第五重。
- 触发对象：股神。
- 触发方式：与股神对话。
- 股神会提示玩家可以前往 A 股门派。
- A 股门派掌门名为东方顺。
- 东方顺当前游戏里还没有，需要后续新增。
- 与股神对话后，激活“与 A 股掌门东方顺对话”的剧情。
- 东方顺会帮助玩家进一步精进《交易心法》。
- 东方顺会传授玩家新的招式。
- 这段剧情之后，主角领悟“器灵之法”。

用户原始剧情意图：

```text
我观察你交易心法已经领悟了第五重。
你现在可以去A股门派，找掌门东方顺（目前我游戏里没有）。
他会帮你再再精进你的交易心法。

我蹉跎半生，都是凡人，不会御剑。
这里展示两种战斗方式。
十年前，我是如此打怪。
十年后，我领悟了器灵御物，我功力大增。
自动化交易的魅力，且看。
这每一把剑都是我的一个策略。
我可以借助器灵，同时驾驭数把武器，结合阵法，同级之内我无敌。
且看万剑归宗。
```

剧情功能：

- 让《交易心法》第五重成为主线进阶门槛。
- 通过股神把玩家从数字门派引导到 A 股门派。
- 引入新 NPC：A 股门派掌门东方顺。
- 引入“器灵御物”概念。
- 用“每一把剑都是一个策略”表达自动化交易的魅力。
- 剧情结束后让主角领悟“器灵之法”。

已确认表现方向：

- 这段剧情会展示两种战斗方式。
- 第一种：东方顺十年前作为凡人，不会御剑时的打怪方式。
- 第二种：东方顺十年后领悟器灵御物后的战斗方式。
- 万剑归宗用于表现“同时驾驭数把武器，结合阵法”。
- 本轮先不定义“器灵之法”的系统归属，只记录为该段剧情后的领悟结果。

待继续确认：

- “两种战斗方式”具体是横版 + 战棋，还是同一战斗系统内的前后对比。
- 东方顺传授的新招式名称。
- 这段剧情是否有战斗胜负，还是纯演示。
- A 股门派在大地图上的位置和进入条件。

### 2.8 核心进阶属性：交易心法

已确认：

- 《交易心法》应该做成独立系统。
- 《交易心法》不属于武功系统。
- 《交易心法》在个人属性面板中占一个固定格子。
- 《交易心法》是一项用于触发交易剧情和开启游戏剧情的核心属性。
- 《交易心法》的重数会成为主线剧情推进条件。
- 数字掌门剧情结束后，主角获得《交易心法》，初始为第一重。
- 已确认的重数剧情节点包括：第五重触发股神引导前往 A 股门派；A 股门派剧情后来到第六层。

实现约束：

- 不把《交易心法》放进武功分类。
- 不把《交易心法》作为普通战斗技能处理。
- 个人面板需要为《交易心法》预留固定展示位置。
- 剧情系统需要能读取《交易心法》的当前重数作为触发条件。

## 5. 剧情数据系统预留需求

后续剧情系统至少需要支持这些数据能力：

- `storyId`：剧情唯一 ID。
- `chapterId`：章节 ID，可选。
- `sceneId`：触发场景。
- `conditions`：触发条件。
- `tradingHeartLevel`：交易心法重数，用于主线剧情触发。
- `steps`：剧情步骤。
- `dialogue`：对话内容。
- `actions`：剧情动作，例如给物品、给秘籍、学武功、提升交易心法重数、开门、开战斗、解锁新剧情点、开启个人面板功能、开启系统任务。
- `flags`：剧情状态标记，例如 A 股门派剧情是否解锁、器灵之法是否领悟、器灵功能是否开启、造物系统任务是否开启。
- `completed`：剧情完成记录。
- `repeatable`：是否可重复触发。
- `priority`：同场景多剧情时的优先级。

注意：这里只是系统能力预留，不代表剧情内容已经确定。

当前已经具备的能力：

- `StorySystem` + `StoryScripts.ts`：支持声明式剧情、条件、节点、选项、完成动作。
- `StoryRegistry.ts`：支持剧情条件和动作，例如设置 flag、发秘籍、加元宝、加好感。
- `SceneManager`：已经负责小屋出生、室内/大地图切换、小屋出口锁定。
- `WorldScene`：已经负责玩家按空格与 NPC / 策略 NPC 交互。
- `digital_sect`：数字门派建筑已经存在于大地图和室内地图。
- `digital_master`：数字掌门已经作为策略 NPC 存在于数字门派。
- `SideBattleSystem`：当前横版战斗已经接入世界。
- `BattleSystem`：战棋战斗系统代码存在，但当前主世界默认没有直接使用它。

当前尚未融合好的地方：

- 股神交互在 `WorldScene` 里是特殊判断：遇到 `gushen` 才启动股神剧情。
- 数字掌门目前是 `StrategyNPC`，按空格默认进入策略聊天，不会先判断主线剧情。
- 数字掌门主线需要“战棋剧情演示”，但当前世界里主要接的是横版战斗。
- 《交易心法》目前还没有作为正式秘籍/心法进度接入玩家成长数据。

### 6.2 推荐抽象

推荐把剧情融合抽象成四层：

| 层级 | 作用 | 当前对应 |
| --- | --- | --- |
| 触发层 | 判断玩家在何处、和谁交互、当前剧情进度是否满足 | `StoryTrigger`、`WorldScene` 交互入口 |
| 剧情层 | 播放对话、选择、旁白、分段剧情 | `StorySystem`、`StoryScripts.ts` |
| 演示层 | 剧情中调用战棋/横版/动画演示 | 需要新增剧情战斗桥接 |
| 奖励/解锁层 | 发秘籍、设置 flag、解锁面板功能、开启任务 | `StoryRegistry.ts` 动作系统 |

核心原则：

- 剧情内容只写在剧情脚本里。
- NPC 是不是策略 NPC，不应该影响它能不能承载主线。
- 战棋和横版都作为剧情可调用的“演示模块”。
- 剧情结束后的奖励、flag、任务开启，都走统一动作系统。

### 6.3 数字掌门主线推荐接入方式

推荐流程：

1. 玩家完成小屋出生剧情，获得 `story.observer_awake = true`。
2. 玩家离开小屋，进入大地图自由探索。
3. 玩家进入数字门派 `digital_sect`。
4. 玩家进入数字掌门 `digital_master` 附近一定距离，或靠近后按空格。
5. 交互路由先判断是否存在未完成主线。
6. 如果数字掌门主线未完成，启动数字掌门主线剧情。
7. 如果数字掌门主线已完成，再回到普通策略 NPC 聊天/查看/切磋逻辑。

建议新增一个“剧情交互路由”：

```text
玩家按空格
  → 找到附近 actor
  → 先查 StoryInteractionRoutes
      → 命中主线：startStoryById(...)
      → 未命中：走原来的聊天/普通对话
```

数字掌门路由示例：

```text
actorId: digital_master
buildingId: digital_sect
conditions:
  - story.observer_awake = true
  - main.digital_master_trial.completed != true
storyId: main_digital_master_trial_intro
fallback: strategy_chat
```

这样不用把数字掌门从策略 NPC 改成普通 NPC，也不破坏他现在的策略档案、实盘数据和切磋能力。

### 6.4 战棋剧情演示推荐接法

第一版建议不要让 `StorySystem` 在同一个脚本里长时间“暂停等待战斗”，而是拆成三段，稳定性更好：

```text
main_digital_master_trial_intro
  → 播放数字掌门对话
  → onComplete 设置 main.digital_master_trial.demo_pending = true
  → 请求启动战棋演示

digital_master_trial_demo
  → 战棋演示：数字掌门展示三招
  → 胜负不影响剧情
  → battle:end 后设置 main.digital_master_trial.demo_done = true

main_digital_master_trial_complete
  → 播放收尾对话
  → 发放秘籍《交易心法》
  → 标记 main.digital_master_trial.completed = true
```

这样做的好处：

- 不会因为 `conv:close` 把正在进行的剧情强制清掉。
- 战斗失败、胜利、跳过都可以统一进入收尾剧情。
- 以后 A 股门派、东方顺、器灵御物，也可以复用同一套“剧情 → 演示 → 收尾奖励”结构。
