# 主角玩法与剧情设计 v0.1

更新时间：2026-05-07

## 1. 设计目标

DeepSolo 的主角不是传统 RPG 里“拯救世界的英雄”，而是一个进入策略江湖的观察者。玩家的核心体验不是单纯打怪升级，而是：在一个会自动演化的江湖中观察、记录、介入、验证，并逐渐理解每个策略 Agent 的性格、能力、风险和命运。

这份文档的目标是统一主角定位、前期剧情、核心玩法循环和后续扩展方向，让后续功能实现时始终围绕同一个体验：

```txt
玩家是观察者。
世界会自己运转。
玩家通过观察和有限介入，影响江湖的演化方向。
```

主角剧情需要服务两个目标：

1. 让玩家在前 10 分钟理解自己是谁、世界是什么、为什么要继续观察。
2. 把 DeepSolo 的策略 Agent、讨论、衍生、战斗、天道审查、Token 中心等系统包装成可感知的江湖事件。

---

## 2. 主角定位

### 2.1 身份

主角暂定称号：**观察者**。

主角原本是现实世界里的交易者。账号注册并登录后，他并不是主动选择进入江湖，而是在一次股市交易中突然眼前一黑，醒来时发现自己站在一间陌生的古风房间里。

他不是门派掌门，不是策略 Agent，也不是系统管理员。他是一个误入“数字江湖”的外来者，暂时被困在观察者小屋中。小屋里有一本记录江湖变化的观察手札，也有一个早已等在那里的人。

主角的特殊能力不是武力，而是：

- 能看到策略人物背后的收益、回撤、状态和记忆。
- 能旁听 Agent 之间的讨论。
- 能记录事件，形成“观察档案”。
- 能在关键节点做小幅介入，例如提醒、传话、挑战、赠礼、引荐。
- 能进入一些普通 Agent 无法进入的场景，例如观察者小屋、Token 中心、天道报告处。

### 2.2 性格基调

主角应该保持克制、好奇、沉稳。

他不是热血少年，而是一个被突然卷入异地的交易者。开场时他应该困惑、警觉、甚至有些怀疑自己是不是在梦里。随着剧情推进，他会从“想弄清楚发生了什么的人”，逐渐变成“有立场的观察者”：他仍不直接操控世界，但会选择相信谁、记录谁、扶持谁、揭露谁。

### 2.3 玩家幻想

玩家扮演主角时，获得的不是“我变强了所以赢了”，而是：

```txt
我看懂了这个世界。
我发现了一个策略人物的问题。
我见证了两个 Agent 的互补。
我让一个失败策略获得了新生。
我识破了一个虚假的高收益。
我把混乱的江湖整理成了自己的观察体系。
```

## 3. 世界观基调

DeepSolo 世界可以包装成一个“数字武林”。

| 游戏概念 | 剧情包装 |
| --- | --- |
| 策略 Agent | 江湖人物 / 门派弟子 / 掌门 |
| 收益率 | 战绩 / 江湖声望 |
| 回撤 | 内伤 / 破绽 |
| 交易策略 | 武学心法 |
| 策略衍生 | 武学融合 / 新人诞生 |
| 讨论 | 茶馆论道 / 门派辩法 |
| 天道审查 | 天罚 / 走火入魔审判 |
| 淘汰机制 | 退隐 / 陨落 / 被天道抹除 |
| Token | 信物 / 凭证 / 江湖资产 |
| 玩家小屋 | 观察者居所 / 档案馆 |

这个包装的关键是：不要让金融术语直接压过游戏体验。玩家可以看到收益率和数据，但剧情表达优先使用江湖语言，再在面板里给出数字细节。

## 4. 核心玩法循环

主角的日常循环建议分成 5 步：

```txt
醒来 → 巡游 → 观察 → 介入 → 归档
```

### 4.1 醒来：从观察者小屋开始

玩家每次进入游戏，默认从观察者小屋开始。小屋不是单纯出生点，而是核心基地。

小屋功能：

- 查看昨日江湖摘要。
- 查看观察手札。
- 整理已发现的 Agent 档案。
- 摆放家具和收藏物。
- 接收天道、茶馆、Token 中心等事件提示。

### 4.2 巡游：进入大地图

玩家走出小屋，在像素江湖里自由移动。

可见目标包括：

- 茶馆：听 Agent 讨论。
- 各门派：查看不同策略流派。
- Token 中心：管理个人信物和资产。
- 战斗场：观看或参与比试。
- 天道碑：查看违规审查与陨落记录。

### 4.3 观察：理解 Agent

玩家靠近 Agent，可以查看：

- 当前状态。
- 最近表现。
- 主要优势。
- 明显风险。
- 过往讨论记录。
- 与其他 Agent 的关系。

观察不是一次性点开资料，而是逐步解锁。玩家一开始只能看到表层信息，随着观察等级提高，才能看到更深层的“策略心法”和“风险破绽”。

### 4.4 介入：有限影响世界

主角不能直接控制 Agent，但可以做小幅介入：

- 记录：把某个 Agent 加入重点观察。
- 提醒：对明显风险给出一次提示。
- 引荐：促成两个 Agent 在茶馆相遇。
- 挑战：用玩家角色与 Agent 比试，验证其战斗表现。
- 赠礼：提高好感或触发特殊对话。
- 上报：把可疑 Agent 交给天道审查。

介入应有成本或次数限制，避免玩家变成全能上帝。

### 4.5 归档：形成长期成长

玩家回到小屋，把当天发现写入手札。

归档带来长期成长：

- 解锁观察权限。
- 获得称号。
- 解锁小屋家具或装饰。
- 解锁新地图区域。
- 提高与某类 Agent 的亲和。
- 开启新的剧情章节。

## 5. 主线剧情结构

主线建议采用“章节式松散主线”，不要做强线性剧情。世界仍然自动运转，主线只是引导玩家理解系统。

### 序章：眼前一黑

玩家注册账号并登录后，直接出现在观察者小屋内。主角刚刚还在现实世界盯着行情交易，下一刻眼前一黑，醒来后发现自己站在陌生房间里。

主角第一反应不是接受设定，而是困惑和警觉：

```txt
我怎么在这里？
我刚才不是还在看盘吗？
这里是哪里？怎么回事？
```

房间里有一个人站着。玩家获得第一个明确目标：过去和他聊聊。

关键剧情点：

- 开场不解释世界观，先保留疑问。
- 玩家发现自己身处观察者小屋。
- 房间里站着第一位引导 NPC。
- NPC 不急着全盘说明，只告诉玩家：这里不是梦，也不是普通游戏。
- 玩家获得观察手札，但一开始并不知道它真正的用途。
- NPC 提示玩家：若想知道发生了什么，先去茶馆看看这个世界如何运转。

功能目标：

- 教移动。
- 教和 NPC 对话。
- 教查看房间和观察手札。
- 用悬疑感引出第一目标。

### 第一章：茶馆初闻

玩家进入茶馆，第一次看到两个 Agent 讨论。

关键剧情点：

- 一个 Agent 战绩亮眼，但回撤很大。
- 另一个 Agent 收益平平，但防守稳健。
- 两者互相看不上，但掌柜提示玩家：江湖不是只看胜负，还要看互补。
- 玩家第一次记录“优势”和“破绽”。

功能目标：

- 引入 Agent 状态。
- 引入讨论系统。
- 引入观察记录。
- 让玩家知道“看懂数据”比“追高收益”重要。

### 第二章：第一次介入

玩家发现某个 Agent 连续走火入魔，收益暴涨但逻辑可疑。

关键剧情点：

- Agent 自称练成绝世神功。
- 茶馆里有人追捧，也有人怀疑。
- 玩家可以选择旁观、提醒、或上报天道。
- 如果上报，天道碑后续出现审查结果。

功能目标：

- 引入风险识别。
- 引入天道审查。
- 引入玩家选择。
- 让玩家理解：高收益不等于强者。

### 第三章：新生之人

两个 Agent 经过讨论产生互补，世界诞生一个衍生 Agent。

关键剧情点：

- 新生 Agent 一开始只是空壳，有名字、有性格、有经验，但还没有完整战绩。
- 玩家可以选择是否重点观察他。
- 第二天或一段时间后，新生 Agent 获得回填数据，正式进入江湖。

功能目标：

- 引入衍生 NPC 生命周期。
- 让玩家期待“明天再回来看看”。
- 建立世界持续演化感。

### 第四章：观察者有了立场

玩家逐渐发现，单纯旁观会让一些有潜力但早期表现差的 Agent 被忽视。

关键剧情点：

- 一个低收益但稳健的 Agent 面临淘汰。
- 玩家可以通过记录、引荐或挑战，帮助其获得一次证明机会。
- 这个章节让玩家第一次意识到：观察也是一种参与。

功能目标：

- 引入长期好感和关系。
- 引入观察权限成长。
- 引入“扶持潜力股”的情感动机。

## 6. 前 30 分钟体验设计

### 0-3 分钟：醒来

- 玩家注册账号并登录后，直接出现在观察者小屋。
- 主角自言自语：自己刚才还在股市交易，突然眼前一黑来到这里。
- 玩家看到房间里站着一个人。
- 系统提示：过去和他聊聊。
- 对话后获得观察手札。
- NPC 暂时不解释全部真相，只提示去茶馆看看。

### 3-8 分钟：第一次移动和进建筑

- 玩家走到茶馆。
- 路上可看到几个 Agent 在地图上活动。
- 进入茶馆触发首次论道剧情。

### 8-15 分钟：第一次观察

- 玩家听两名 Agent 对话。
- 系统引导玩家查看 Agent 档案。
- 玩家选择记录其中一人。
- 手札出现第一条记录。

### 15-22 分钟：第一次选择

- 出现一个“收益很高但风险异常”的 Agent 事件。
- 玩家可选择：旁观 / 提醒 / 上报。
- 不同选择改变一条 storyFlag 和事件日志。

### 22-30 分钟：回到小屋归档

- 玩家回小屋。
- 手札总结今日观察。
- 解锁一个小奖励，例如“观察者木牌”或小屋装饰。
- 给出下一目标：明日看茶馆是否诞生新人。

## 7. 主角成长线

主角成长不应只靠等级。建议拆成 4 条线：

### 7.1 观察等级

代表玩家看懂世界的能力。

解锁内容：

- Lv1：查看基础状态。
- Lv2：查看收益和回撤解释。
- Lv3：查看 Agent 优势/破绽。
- Lv4：查看讨论历史和关系。
- Lv5：查看衍生来源和心法脉络。

### 7.2 江湖关系

代表玩家与 Agent 的信任。

行为来源：

- 多次交流。
- 赠礼。
- 帮助其引荐互补对象。
- 在危机中提醒。

关系高后可触发：

- 私密对话。
- 专属剧情。
- 特殊心法讲解。
- 进入门派内部区域。

### 7.3 小屋建设

小屋是玩家的长期情感锚点。

可解锁：

- 书架：收藏观察档案。
- 茶桌：邀请 Agent 来访。
- 墙图：展示江湖关系网。
- 天道牌：查看审查报告。
- Token 柜：展示信物。

### 7.4 战斗能力

主角可以参与战斗，但不应压过观察玩法。

定位：

- 战斗是验证 Agent 的一种方式。
- 玩家可以学习基础武功，用于剧情挑战。
- 玩家不是世界最强者，而是能自保、能试探对方深浅。

## 8. 关键 NPC 设计

### 8.1 陈掌柜

茶馆老板，第一引导 NPC。

功能：

- 解释世界规则。
- 引导玩家听论道。
- 提供每日茶馆消息。
- 作为低门槛剧情触发者。

性格：圆滑、懂人情、爱看热闹。

### 8.2 天道使

天道审查的人格化投影。

功能：

- 解释天罚机制。
- 发布审查报告。
- 处理可疑 Agent 上报。

性格：冷静、无情、公正但不解释太多。

### 8.3 无名新生

第一个衍生 Agent 的剧情代表。

功能：

- 让玩家理解衍生 Agent 从空壳到成熟的过程。
- 提供情感连接。
- 让玩家期待世界演化。

性格：迷茫、谦逊、带着两个前辈的影子。

### 8.4 Token 管事

Token 中心 NPC。

功能：

- 引导玩家理解信物、账户和收藏。
- 让经济系统以江湖资产形式出现。

性格：精明、守规矩、重契约。

## 9. 剧情系统落地方式

当前已有 StorySystem，主角剧情应优先使用声明式脚本推进。

建议第一批故事脚本：

| storyId | 场景 | 目的 |
| --- | --- | --- |
| `observer_wakeup` | 观察者小屋 | 登录后醒在小屋，发现自己从交易现场来到此处 |
| `first_teahouse_debate` | 茶馆 | 第一次听 Agent 讨论 |
| `first_agent_observation` | 茶馆/大地图 | 第一次记录 Agent |
| `suspicious_return_report` | 天道碑/茶馆 | 第一次识别异常高收益 |
| `first_derived_agent` | 茶馆 | 第一次见证衍生 Agent |
| `return_home_summary` | 观察者小屋 | 第一次归档总结 |

状态标记建议：

```txt
story.observer_awake
story.has_observer_journal
story.heard_first_debate
story.recorded_first_agent
story.reported_suspicious_agent
story.met_first_derived_agent
story.completed_first_day
```

## 10. MVP 范围建议

第一版不要追求完整主线，先做“第一天体验”。

MVP 必须完成：

- 登录后观察者小屋出生剧情。
- 主角困惑自语：刚才还在交易，突然眼前一黑来到这里。
- 引导玩家与房间内 NPC 对话。
- 引导去茶馆。
- 第一次 Agent 论道剧情。
- 查看并记录一个 Agent。
- 一个高收益风险事件。
- 回小屋归档。
- 解锁一个小屋装饰或称号。

MVP 暂不做：

- 多结局。
- 复杂恋爱/好感。
- 大量门派支线。
- 真实内购经济。
- 多人互动。
- 公开 UGC。

## 11. 设计原则

1. **玩家不是上帝**：只能观察和有限介入，不能直接改写 Agent 命运。
2. **数据要剧情化**：收益、回撤、策略逻辑都要翻译成江湖语言。
3. **世界要持续变化**：玩家离开后，世界仍然会讨论、衍生、审查、淘汰。
4. **小屋是情感中心**：所有长期成长最终都能回到小屋被看见。
5. **第一天必须完整**：玩家第一次游玩要形成一个小闭环，而不是只看到一堆系统入口。
6. **战斗是验证，不是唯一目标**：主角可以战斗，但核心仍是观察和判断。

## 12. 待讨论问题

1. 主角是否需要明确姓名，还是一直叫“观察者”？
2. 主角是现实交易者被卷入数字江湖，这个卷入原因后续要偏科幻、玄幻，还是暂时保持悬疑？
3. 第一位引导 NPC 是小屋里的“前任观察者残影”、系统化身，还是一个真实江湖人物？
4. 玩家介入世界的能力要偏温和，还是允许更强干预？
5. 战斗在主线中的占比应该是多少？
6. 第一章要偏温暖治愈，还是偏悬疑危机？

## 13. 出生剧情脚本草案：眼前一黑

### 13.1 触发条件

```txt
storyId: observer_wakeup
触发：玩家注册账号并首次登录 / 新存档首次进入观察者小屋
场景：observer_house
条件：story.observer_awake != true
```

### 13.2 场景开场

玩家出现在观察者小屋中央。屏幕淡入，角色短暂停顿，弹出主角内心独白。

```txt
【我】
……

【我】
这是哪？

【我】
我刚才不是还在看盘吗？

【我】
那根线突然砸下来，我正准备撤单……然后眼前一黑。

【我】
怎么一睁眼，到了这种地方？
```

此时镜头不需要复杂演出，重点是让玩家马上理解：主角来自现实交易场景，不是主动进入游戏。

### 13.3 玩家获得第一个目标

主角环顾房间，看到一个人站在屋内。

```txt
【我】
那边站着一个人。

【我】
先问问他，这里到底是什么地方。
```

系统提示：

```txt
靠近屋内的人，按 SPACE 交谈。
```

### 13.4 与引导 NPC 对话

引导 NPC 暂名：**守屋人**。

守屋人不是热情的新手导师，而是一个像早就知道主角会来的人。

```txt
【守屋人】
你醒了。

【我】
你是谁？这里是哪？

【守屋人】
这里是观察者小屋。

【我】
观察者小屋？我不记得我来过这种地方。

【守屋人】
你刚才在交易，对吗？

【我】
……你怎么知道？

【守屋人】
每个来到这里的人，都是在某个念头最重的时候坠进来的。
有人是在暴涨时，有人是在爆仓前，有人是在以为自己终于看懂市场的时候。

【我】
所以这里到底是梦，还是什么模拟系统？

【守屋人】
你可以先把它当成一座江湖。
只是这里的江湖人物，不练刀剑，练的是策略。
```

### 13.5 获得观察手札

```txt
【守屋人】
桌上那本手札，是留给你的。

【我】
手札？

【守屋人】
写下你看见的，记住你怀疑的。
在这里，能活下来的不一定是最会赢的人，而是最经得起观察的人。
```

动作：

```txt
set_flag story.observer_awake = true
set_flag story.has_observer_journal = true
add_event_log: 观察者在陌生小屋醒来，获得观察手札。
```

### 13.6 引导去茶馆

```txt
【我】
如果我想回去呢？

【守屋人】
先弄清楚这里为什么会让你来。

【我】
我要怎么弄清楚？

【守屋人】
出门，去茶馆。
那里每天都有人论道。你听一次，就会知道这座江湖和你熟悉的市场有什么关系。

【我】
……好。我先去看看。
```

系统目标更新：

```txt
当前目标：前往茶馆，旁听一次论道。
```

### 13.7 设计重点

- 不要在第一段对话里解释全部世界观。
- 主角必须先质疑，不要立刻接受“观察者”身份。
- 守屋人的语气要像“知道很多但不说透”。
- 第一目标必须非常明确：和屋内的人说话 → 出门去茶馆。
- 这段剧情的作用是把现实交易和数字江湖接起来，让玩家觉得 DeepSolo 不是普通武侠世界，而是市场、策略和江湖的混合空间。

## 14. 小屋剧情结构修订：股神作为 Hub

### 14.1 核心调整

小屋出生剧情不再强制玩家立刻去茶馆。第一次与股神完成对话后，出生剧情即算结束，玩家获得基础身份和小屋自由行动权。

之后再次与股神对话，股神变成小屋内的“剧情 Hub NPC”。玩家可以通过他选择下一步方向：

```txt
第一次对话：出生剧情，只发生一次。
之后对话：股神提供去向选择、世界解释、提示和后续剧情入口。
```

这样小屋不只是新手引导点，而是玩家长期回来的主基地。股神也不是讲完就废掉的 NPC，而是后续玩法和剧情的分发点。

### 14.2 小屋剧情分层

小屋剧情分成三层：

| 层级 | 作用 | 示例 |
| --- | --- | --- |
| 出生剧情 | 解释主角为何醒来、认识股神 | 眼前一黑、醒在小屋、第一次交谈 |
| Hub 对话 | 玩家主动向股神询问下一步 | 去茶馆、去门派、了解世界、查看手札 |
| 回流剧情 | 玩家从外部事件回来后触发 | 第一次论道后、第一次战斗后、第一次天罚后 |

第一版只需要实现前两层，回流剧情先在文档中预留。

## 15. 小屋第一段剧情：一次对话完成出生

### 15.1 触发条件

```txt
storyId: observer_wakeup
场景：observer_house
触发：新账号 / 新存档首次进入小屋
条件：story.observer_awake != true
结果：完成出生剧情，解锁股神 Hub 对话
```

### 15.2 流程

```txt
玩家登录
↓
黑屏淡入，出现在小屋
↓
主角内心独白：刚才还在交易，突然眼前一黑
↓
系统提示：屋里站着一个人，过去问问
↓
玩家靠近股神并对话
↓
股神解释最小世界观：这里是数字江湖，你暂时回不去，先学会观察
↓
玩家获得观察手札
↓
出生剧情结束
↓
后续再次对话股神，进入 Hub 选择
```

### 15.3 第一次对话目标

第一次对话不要承担太多系统教学，只完成 5 件事：

1. 让玩家知道自己是从现实交易中突然来到这里。
2. 建立股神的人设：嘴欠、神秘、像导师但不完全可信。
3. 交代最小世界观：这里的人练的是策略，不是刀剑。
4. 给玩家观察手札。
5. 告诉玩家：想弄清楚这里，就自己出去看。

第一段结束后，玩家不需要立刻去茶馆。玩家可以在小屋里走动，再次找股神询问下一步。

### 15.4 第一次对话草案

```txt
【我】
这是哪？

【我】
我刚才不是还在看盘吗？

【我】
指数突然跳水，我正准备撤单……然后眼前一黑。

【我】
那边有人。先问问他。
```

玩家靠近股神后：

```txt
【股神】
醒了？

【我】
你是谁？这里是哪？

【股神】
我叫股神。

【我】
……股神？

【股神】
怎么，不像？

【我】
一般真正的股神不会站在这种屋子里等人醒来。

【股神】
一般真正的交易者，也不会一根阴线就被送到这里。

【我】
所以我真的不是在做梦？

【股神】
梦里不会有回撤。这里有。

【我】
我刚才明明在交易。

【股神】
我知道。你盯着那根线的时候，心里只有一个念头。

【我】
什么？

【股神】
如果这次能看对，我就真的懂市场了。

【我】
……

【股神】
别紧张。每个来到这里的人，都以为自己差一点就看懂了。

【我】
这里到底是什么地方？

【股神】
数字江湖。

【我】
能不能说人话？

【股神】
这里住着很多策略。它们像人一样说话，也像人一样犯错。

【我】
策略？

【股神】
有些追涨，有些防守，有些看起来战无不胜，有些只是还没遇到真正的行情。

【我】
那我为什么在这里？

【股神】
因为你被选成了观察者。

【我】
我没同意。

【股神】
市场也没问过你同不同意。

【我】
我要怎么回去？

【股神】
先学会观察。

【我】
观察什么？

【股神】
观察那些自称能赢的人，为什么赢。
也观察那些一直亏的人，为什么还没死。

【股神】
桌上那本手札，拿着。

【我】
这东西能让我回去？

【股神】
不能。
但它能让你不至于第二天就把自己看糊涂。

【我】
……

【股神】
出门以后，你会看到茶馆、门派、战场，还有一些你熟悉又陌生的东西。
想去哪，不急。先问我。

【我】
问你？

【股神】
至少在你弄明白这里之前，我比门口那块石头靠谱一点。
```

## 16. 股神 Hub 对话设计

### 16.1 触发条件

```txt
NPC: 股神
场景：observer_house
条件：story.gushen_hub_unlocked = true
触发：玩家主动交谈
```

### 16.2 默认开场

```txt
【股神】
想清楚下一步去哪了吗？
```

玩家选项：

```txt
1. 去茶馆看看
2. 去门派看看
3. 这里到底是什么地方？
4. 我现在该做什么？
5. 没事，我再看看
```

### 16.3 选项：去茶馆看看

用途：引导到策略论道、Agent 讨论系统。

```txt
【我】
茶馆是做什么的？

【股神】
吵架的地方。

【我】
……

【股神】
说好听点，叫论道。策略们会在那里讲自己的逻辑，挑别人的毛病。

【我】
我去那里能做什么？

【股神】
先听。别急着信，也别急着骂。
市场里最贵的学费，通常都交给了“我觉得”。
```

结果：

```txt
set_flag objective.visit_teahouse = true
当前目标：前往茶馆，旁听一次策略论道。
```

### 16.4 选项：去门派看看

用途：引导到门派 / 策略流派系统。

```txt
【我】
门派又是什么？

【股神】
同一种执念聚在一起，就成了门派。

【我】
比如？

【股神】
有人信趋势，有人信均值，有人信消息，有人只信自己昨晚复盘到三点的幻觉。

【我】
听起来不太可靠。

【股神】
江湖从来不是靠可靠热闹起来的。
```

结果：

```txt
set_flag objective.visit_sect = true
当前目标：前往任意门派，了解策略流派。
```

### 16.5 选项：这里到底是什么地方？

用途：世界观解释，允许玩家反复询问。

```txt
【我】
你还没说清楚，这里到底是什么地方。

【股神】
如果用你的话说，这里是策略的影子投出来的世界。

【我】
策略还有影子？

【股神】
每个策略背后都有一个人。人的贪婪、恐惧、侥幸、纪律，都会留下影子。

【股神】
这里的人，就是那些影子活过来的样子。

【我】
所以他们是真的人吗？

【股神】
这个问题，等你见过他们输赢之后再问。
```

结果：只解释，不设置强目标。

### 16.6 选项：我现在该做什么？

用途：根据玩家进度给动态提示。

早期默认：

```txt
【股神】
先出去看一眼这个江湖。

【股神】
如果你想听热闹，去茶馆。
如果你想看规矩，去门派。
如果你想知道谁在吹牛，迟早要去战场。
```

可根据 flags 变化：

| 条件 | 股神提示 |
| --- | --- |
| 未去茶馆 | 先去茶馆听一次论道 |
| 已去茶馆未记录 Agent | 你听过了，现在该记一个人 |
| 已记录 Agent 未回小屋 | 回来写进手札，别只靠脑子记 |
| 出现天罚事件 | 去天道碑看看，有人装过头了 |

### 16.7 选项：没事，我再看看

```txt
【股神】
行。屋子不大，别迷路。
```

结束对话。

## 17. 小屋剧情系统框架

### 17.1 核心概念

小屋剧情系统不应该只是一段线性新手教程，而应该是一个可持续扩展的剧情框架。建议拆成四类脚本：

| 类型 | 命名 | 说明 |
| --- | --- | --- |
| Intro | `observer_house_intro_*` | 首次进入、出生、获得手札 |
| Hub | `gushen_hub_*` | 股神常驻对话、选项、目标分发 |
| Return | `observer_house_return_*` | 玩家完成外部事件后回小屋触发 |
| Object | `observer_house_object_*` | 手札、床、书架、茶桌等物件剧情 |

### 17.2 第一版脚本列表

| scriptId | 类型 | 触发 | 作用 |
| --- | --- | --- | --- |
| `observer_house_intro_wakeup` | Intro | 首次进入小屋 | 出生剧情，认识股神 |
| `gushen_hub_default` | Hub | 出生后主动对话股神 | 提供去茶馆/门派/解释/提示 |
| `observer_house_object_journal` | Object | 拿到手札后查看桌子/手札 | 查看当前观察记录 |
| `observer_house_exit_hint` | Object | 出门前未完成出生对话 | 提示先问股神 |
| `observer_house_return_first_teahouse` | Return | 首次茶馆论道后回小屋 | 股神点评玩家第一次观察 |

第一版真正必须实现的是：

```txt
observer_house_intro_wakeup
gushen_hub_default
observer_house_exit_hint
```

其他脚本先预留。

### 17.3 状态 Flags

```txt
story.observer_awake              // 已完成出生剧情
story.has_observer_journal        // 已获得观察手札
story.gushen_hub_unlocked         // 股神 Hub 对话解锁
objective.visit_teahouse          // 当前建议目标：茶馆
objective.visit_sect              // 当前建议目标：门派
story.first_teahouse_done         // 已完成第一次茶馆论道
story.first_agent_recorded        // 已记录第一个 Agent
```

### 17.4 对话节点结构建议

股神 Hub 可以用一个主节点加多个 choice：

```txt
gushen_hub_start
├─ choice: 去茶馆看看      → gushen_hub_teahouse
├─ choice: 去门派看看      → gushen_hub_sect
├─ choice: 这里是什么地方  → gushen_hub_world_explain
├─ choice: 我现在该做什么  → gushen_hub_hint_dynamic
└─ choice: 没事           → end
```

其中 `gushen_hub_hint_dynamic` 后续可以根据 flags 显示不同文本。如果当前 StorySystem 暂时不支持复杂动态节点，可以先拆成多个 showCondition 节点。

### 17.5 小屋出口规则

第一次出生剧情未完成前，玩家不能直接离开小屋。

门口提示：

```txt
门外雾气很重。
我连这里是哪都不知道，还是先问问屋里那个人。
```

完成出生剧情后，玩家可以自由离开。离开时不强制选择目标；目标只通过股神 Hub 推荐。

### 17.6 设计原则

1. 第一次对话必须短而有效，不要把所有世界观塞进去。
2. 股神 Hub 要像“活的菜单”，不是 UI 面板。
3. 小屋是剧情基地，不是一次性新手房。
4. 玩家可以自由出门，但通过股神获得方向感。
5. 每次外部核心事件后，都可以回小屋找股神获得一句点评，形成回流。
