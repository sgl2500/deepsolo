## 一、战斗流程总览

```
WarMain(warid, isexp)
  ├─ WarLoad(warid)              // 加载战斗数据 war.sta
  ├─ WarSelectTeam()             // 选择己方参战队员（最多6人）
  ├─ WarSelectEnemy()            // 选择敌方（最多20人）
  ├─ WarLoadMap(mapid)           // 加载战场地图 (64×64)
  ├─ WarPersonSort()             // 按轻功降序排列所有角色
  ├─ 计算初始 Time 值            // 800 - i * 1000/PersonNum
  ├─ 计算移动步数                // getnewmove(轻功) 减去中毒/受伤修正
  └─ 主循环 while true
       ├─ 所有角色 Time += 轻功
       ├─ 谁的 Time >= 1000 → 行动
       │   ├─ 己方: 手动/自动
       │   └─ 敌方: War_Auto()
       │        ├─ War_Think() → 决策类型
       │        │   ├─ 0: 休息
       │        │   ├─ 1: 攻击
       │        │   ├─ 2: 吃药（内力）
       │        │   ├─ 3: 吃药（生命）
       │        │   ├─ 4: 吃药（低内力）
       │        │   ├─ 5: 找医生治疗
       │        │   ├─ 6: 吃解毒药
       │        │   └─ 7: 休息一回合
       │        └─ War_AutoFight() → 选武功 → 移动+攻击
       ├─ 行动后: Time -= 1000
       ├─ 毒伤结算、状态恢复
       └─ 检查胜负 War_isEnd()
```

## 二、行动顺序 — ATB 时间槽系统

JYQXZ 使用 **ATB（Active Time Battle）** 而非传统回合制。

### 核心机制

```lua
-- 每帧给所有存活角色的 Time 增加其轻功值
for i = 0, WAR.PersonNum - 1 do
    if not dead then
        WAR.Person[i].Time = WAR.Person[i].Time + WAR.Person[i]["轻功"]
    end
end

-- 当 Time >= 1000 时该角色行动
if WAR.Person[p].Time > 1000 then
    -- 该角色获得行动机会
    -- 行动后:
    WAR.Person[p].Time = WAR.Person[p].Time - 1000
    if WAR.Person[p].Time < -500 then
        WAR.Person[p].Time = -500
    end
end
```

### 初始 Time

```lua
WAR.Person[i].Time = 800 - i * 1000 / WAR.PersonNum
```

轻功最高的角色排在最前面（i=0），初始 Time 最接近 1000，会最先行动。

### 轻功计算

```lua
轻功 = 基础轻功 + 装备轻功加成 + 缘分轻功加成
     + (对敌方) 内力最大值/100
```

### 移动步数计算

```lua
function getnewmove(x)    -- x = 轻功值
    if x > 150 then return 7 + (x - 150) / 80
    elseif x > 70 then return 5 + (x - 70) / 40
    elseif x > 30 then return 3 + (x - 30) / 20
    else return x / 10
    end
end

移动步数 = getnewmove(轻功) - 中毒程度/50 - 受伤程度/60 + 等级/70 - 1
-- 最小为 1，最大为 10
```

### 武功等级

```lua
if level == 999 then

```

```
atkfanwei = {a1, a2, a3, a4, a5}  -- 攻击范围形状（十字形）
```

攻击范围通过 `WarDrawAtt(x, y, atkfanwei, flag)` 绘制到战场 WarMap 的第4层。

## 五、伤害计算 — 核心公式

这是 `War_WugongHurtLife()` 函数的核心逻辑（约1200行）。

### 5.1 基础伤害

```lua
-- 武功基础伤害 = 武功威力[level] / 4
hurt = JY.Wugong[wugong]["攻击力" .. level] / 4

-- 如果等级 > 10（极端情况）:
hurt = JY.Wugong[wugong]["攻击力10"] / 3
```

### 5.2 攻防比

```lua
atk = JY.Person[pid]["攻击力"]
def = JY.Person[eid]["防御力"]

-- 内力等效（getnl函数）
function getnl(id)
    return (内力 * 2 + 内力最大值) / 3
end

-- 攻击方额外加成
atk = atk + t * getnl(pid) / 50
hurt = hurt + atk / 4

-- 防御方减伤
def = def + 1.2 * getnl(eid) / 40 + 敌方武学常识

-- 攻击方额外加成
atk = atk + 己方武学常识 + ang/10

-- 最终伤害
hurt = hurt * atk / (atk + def)
```

其中 `t` 对己方为 1.0，对敌方为 1.5~2.0（敌方有伤害加成）。

### 5.3 装备附加伤害

```lua
-- 攻击方武器附加随机伤害
hurt = hurt + random(武器.攻击加成 * 0.5 ~ 武器.攻击加成)
-- 防御方防具减伤
hurt = hurt - random(防具.防御加成 * 0.5 ~ 防具.防御加成)
```

### 5.4 属性修正

```lua
hurt = hurt
    - def / 12                          -- 防御折减
    + 攻击方等级 / 5 - 防御方等级 / 5     -- 等级差
    + 防御方受伤程度 / 3 - 攻击方受伤程度 / 3
    + 防御方中毒程度 / 2 - 攻击方中毒程度 / 2
    - 内功反击值 / 30                    -- 被动内功减伤
```

### 5.5 距离衰减

```lua
-- 己方攻击有距离衰减
offset = |攻击方X - 防御方X| + |攻击方Y - 防御方Y|
if offset < 10 then
    hurt = hurt * (100 - (offset - 1) * 3) / 100
end

-- 敌方只有 2/3 伤害
-- (对敌方: hurt = hurt * 2/3)
```

### 5.6 暴击系统

```lua
-- 暴击率计算
BJ = 攻击力/18 + (内力最大值+内力)/1000 + 等级/10
   + 特定武功加成(每个+5)
   + 实战经验加成
   + (敌方 +20)
   
BJ = clamp(BJ, 10, 100)

-- 判定
if random(200) > 60 and random(200) < 60 + BJ then
    WAR.BJ = 1   -- 暴击
end

-- 暴击伤害
if 暴击 then
    hurt = hurt * 1.5    -- 普通角色暴击 1.5x
    -- 特定角色 (胡斐/程灵素等) 暴击 2x
end
```

### 5.7 连击系统

```lua
-- 连击率计算
LJ = 轻功/18 + (内力最大值+内力)/1000 + 等级/10
   + 特定剑法武功加成(每个+5)
   + 实战经验加成
   
LJ = clamp(LJ, 10, 100)

-- 判定
if random(200) > 60 and random(200) < 60 + LJ then
    fightnum = 2   -- 连击（攻击2次）
end

-- 特殊角色可以连击3次甚至5次
```

### 5.8 内功反击（被动技能）

```lua
-- 防御方内功判定
for i = 1, 10 do
    kfid = JY.Person[eid]["武功" .. i]
    -- 九阳神功(95)、乾坤大挪移(97)、小无相功(101) 等
    if 是高概率反击内功 then
        if defRandom(30, eid) then   -- 防御方判定
            dng = JY.Wugong[kfid]["攻击力" .. lv]
        end
    end
end

-- 反击伤害直接加到 dng 上，最终减伤
hurt = hurt - dng/30
```

### 5.9 特殊角色加成

原版有大量特殊角色的专属加成，例如：
- **东方不败**: 伤害 ×1.5
- **谢逊/鳌拜**: 被攻击伤害 ×0.6
- **胡斐**: 血量低于一半时暴击率大增
- **乔峰**: 降龙十八掌有额外连击
- **令狐冲**: 独孤九剑有特殊加成
- **韦小宝**: 品德影响伤害
- 等等...

### 5.10 武功类型克制

```lua
-- 化学系（拳学/化学伤害）额外加成
if 拳学/化学 then
    hurt = hurt * 1.3
end
```

## 六、命中判定

JYQXZ 的命中不是简单的命中率，而是一个多因素概率系统。

### 攻击判定 (`atkRandom`)

```lua
function atkRandom(jl, p)   -- jl=初始概率, p=判定者
    atk = 攻击力 + 装备攻击加成 + 缘分攻击加成
    
    jl = jl + clamp(atk / 15, 0, 40)   -- 攻击力贡献
    jl = jl + baseRandom(p)             -- 基础概率
    
    return jl > random(110)
end
```

### 基础概率 (`baseRandom`)

```lua
function baseRandom(p)
    jl = 0
    jl = jl + clamp(品德 / 800, 0, 12)                    -- 品德贡献
    jl = jl + 内力最大值 * 2 / (内力 + 100)                 -- 内力贡献
    jl = jl + 实战经验加成(最多20)                           -- 实战贡献
    jl = jl + 特定武功加成(太极神功每级+1)
    jl = jl + 内力战火加成(+20)
    jl = jl + (非己方+10)                                   -- 敌方额外加成
    return jl
end
```

### 判定使用场景

- `atkRandom(30, pid)`: 攻击方发动内功反击
- `defRandom(30, eid)`: 防御方发动内功反击
- `spdRandom(jl, p)`: 轻功相关判定
- `atkdefRandom(jl, p)`: 攻防综合判定

## 七、AI 决策系统

### War_Think() — AI决策入口

```
决策优先级:
1. 内力 < 10 → 吃补内力药 / 休息
2. 内力 < 20 或 受伤 > 50 → 吃补内力药
3. 生命 < 1/5 最大值 → 90%概率吃补血药
4. 生命 < 1/4 → 70%概率吃补血药
5. 生命 < 1/3 → 50%概率吃补血药
6. 生命 < 1/2 → 25%概率吃补血药
7. 中毒程度 > 3/4 上限 → 60%概率吃解毒药
8. 中毒程度 > 1/2 上限 → 30%概率吃解毒药
9. 内力够用最低武功消耗 → 攻击
10. 否则 → 休息
```

### War_AutoSelectWugong() — AI选择武功

```lua
-- 选择逻辑:
-- 1. 遍历所有已学武功
-- 2. 计算每个武功的攻击范围
-- 3. 评估能打到多少敌人
-- 4. 选择覆盖敌人最多的武功
-- 5. 如果有多个同分，随机选择
```

### 移动+攻击决策 (`unnamed` 函数)

```
1. 计算所有可移动位置
2. 对每个位置，计算攻击范围覆盖的敌人
3. 按覆盖分排序
4. 保留分 >= 最高分/2 的位置
5. 加上地形分数（GetMovePoint）
6. 重新排序
7. 保留分 >= 最高分*4/5 的位置
8. 选择第1名位置移动，然后攻击
9. 如果没有任何位置能打到敌人 → 朝最近敌人移动
```

### War_AutoDoctor() — AI使用医术

```
-- 寻找己方受伤最重的角色
-- 如果在治疗范围内 → 治疗之
-- 否则 → 移动靠近
```

### War_AutoEatDrug() — AI使用物品

```
flag:
2 = 补内力
3 = 补生命
4 = 低内力
6 = 解毒
```

## 十、毒/伤/医系统

### 毒伤结算 (`War_PoisonHurt`)

```lua
-- 每回合结束时:
-- 如果角色中毒程度 > 0
--   生命 -= 中毒伤害
```

### 受伤程度影响

```
受伤程度影响:
  - 降低移动步数: 移动步数 -= 受伤程度/60
  - 降低伤害输出: hurt -= 受伤程度/3

```

```
医术能力 >= 20 的角色可以治疗队友
```

## 十二、与 DeepSolo 当前实现的对比

| 维度 | JYQXZ 原版 | DeepSolo 当前 |
|------|-----------|--------------|
| 行动顺序 | ATB时间槽（轻功驱动） | 回合制（轻功排序） |
| 伤害公式 | 复杂多因素（攻防比+内力+等级+受伤+中毒+距离衰减+装备+角色特殊+内功反击+...） | 简化版 `power * atk/(atk+def+50) * random(0.85~1.15)` |
| 命中判定 | 多因素概率系统（攻防判定函数） | 固定命中率 85%~95% |
| 暴击系统 | 攻/内/等级/武功/实战 综合概率 | 无 |
| 连击系统 | 轻功/内力/武功 综合概率 | 无 |
| 内功反击 | 被动技能，概率触发，减少伤害 | 无 |
| 武功等级 | 10级 + 极(999)，影响威力和范围 | 无等级 |
| 移动步数 | 轻功/受伤/中毒/等级 动态计算 | 固定 moveRange |

## 十三、DeepSolo 战斗系统改进建议

### 优先级 P0（核心体验）

1. **ATB 时间槽系统**: 替换当前回合制，让轻功真正影响行动频率
2. **伤害公式增强**: 加入内力等效、距离衰减、受伤/中毒影响
3. **暴击系统**: 基于攻击力的暴击率 + 1.5倍伤害

### 优先级 P1（深度）

4. **连击系统**: 基于轻功的二次攻击概率
5. **武功等级**: 每个武功10级，升级增加威力/范围
6. **AI增强**: 考虑HP/MP/距离/武功范围的综合决策
7. **属性状态**: 受伤/中毒系统

### 优先级 P2（完整度）

8. **内功反击**: 被动技能触发
9. **地形系统**: 战场有水域/山地/障碍
10. **物品系统**: 战斗中使用药品
